
# OpenShift prerequisites

**Supported configuration:** https://access.redhat.com/articles/rhoai-supported-configs-3.x (OpenShift 4.20)

All these operators should be installed :

1. Authorino Operator (Red Hat)
2. OpenShift Service Mesh 3 (Red Hat)
3. OpenShift Serverless (Red Hat)
4. JobSet Operator (Red Hat)
5. Connectivity Link (Red Hat) : Needed by llm-d
6. Leader Worker Set Operator (Red Hat) : Needed by llm-d
7. Red Hat build of Kueue
8. OpenShift AI Operator (Red Hat)
